这道CTF题目考察的是**有偏随机数（Biased Randomness）**引发的统计学攻击（或相关性攻击）。

核心漏洞分析

  1. 随机数生成器 (gen 函数) 存在偏差：
    代码中的随机位生成逻辑是 randint(1, 7) % 2。

    • randint(1, 7) 生成 1 到 7 之间的整数（包含 1 和 7）。
    • 集合为 {1, 2, 3, 4, 5, 6, 7}。
    • 对 2 取模的结果：
      • 奇数 (1, 3, 5, 7) -> 结果为 1 (共4个)
      • 偶数 (2, 4, 6) -> 结果为 0 (共3个)
    • 偏差：生成 1 的概率是 4/7≈57.1%4/7 \approx 57.1\%4/7≈57.1%，生成 0 的概率是 3/7≈42.9%3/7 \approx 42.9\%3/7≈42.9%。这不是均匀分布的随机数。

  2. 异或运算的统计特性：
    otp() 函数返回 key ^ random_mask。

    • 假设 Key 的某一位是 kkk，Mask 的对应位是 rrr。
    • 如果 k=0k = 0k=0，则输出 0⊕r=r0 \oplus r = r0⊕r=r。输出结果倾向于 Mask 的分布（1 多 0 少）。
    • 如果 k=1k = 1k=1，则输出 1⊕r=¬r1 \oplus r = \neg r1⊕r=¬r。输出结果会反转 Mask 的分布（0 多 1 少）。

  3. 攻击方法：
    根据大数定律，我们可以多次请求 otp()，收集大量的样本。对于每一位（bit）：

    • 统计该位为 1 的频率。
    • 如果频率显著大于 0.5（接近 4/7），则 Key 的该位为 0。
    • 如果频率显著小于 0.5（接近 3/7），则 Key 的该位为 1。

完整的解题脚本 (Solution Script)

你需要安装 pwntools 库 (pip install pwntools) 来运行此脚本。为了在本地测试，请确保当前目录下有题目给出的 Subgroup-Weaver.py 以及一个包含 flag = "CTF{test_flag}" 的 secret.py 文件。

代码详细解释

  1. 样本收集 (for i in range(SAMPLE_SIZE)):

    • 脚本模拟与服务器的交互。程序处于 while 循环中，只要输入的不是 Key，就会打印 otp() 的结果。
    • 我们发送垃圾数据（例如 b'get_sample'），服务器就会返回一个大整数。
    • 我们收集 500 个这样的大整数。

  2. 位统计 (bit_counts):

    • Key 的长度是 64 字节，即 64×8=51264 \times 8 = 51264×8=512 比特。
    • 我们创建了一个长度为 512 的数组 bit_counts。
    • 对于每一个返回的整数，检查它的第 0 位到第 511 位。如果某一位是 1，就在数组对应位置加 1。

  3. 密钥重构 (核心逻辑):

    • 理论基础：
      • Mask 的生成逻辑是 randint(1,7)%2。
      • P(Mask=1)=4/7≈0.571P(\text{Mask}=1) = 4/7 \approx 0.571P(Mask=1)=4/7≈0.571
      • P(Mask=0)=3/7≈0.428P(\text{Mask}=0) = 3/7 \approx 0.428P(Mask=0)=3/7≈0.428
    • 判断逻辑：
      • 计算每一位出现 1 的频率 freq = count / total。
      • 如果 freq > 0.5（接近 0.57）：这意味着 Output 的分布和 Mask 相同（1多0少）。根据异或性质 0⊕x=x0 \oplus x = x0⊕x=x，说明 Key 的这一位是 0。
      • 如果 freq < 0.5（接近 0.43）：这意味着 Output 的分布和 Mask 相反（1少0多，即0变成了1，1变成了0）。根据异或性质 1⊕x=¬x1 \oplus x = \neg x1⊕x=¬x，说明 Key 的这一位是 1。

  4. 提交与获取 Flag:

    • 利用位运算 |= (1 << bit_idx) 将判断出的位组装回整数。
    • 转成十六进制字符串发送给服务器，即可通过验证并获取 Flag。
